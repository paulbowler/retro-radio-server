Technical setup

For the person who set up Retro Radio.

Server address

{{.Base}}

Radio connection

Point pure.wifiradiofrontier.com to this computer’s local network address. Retro Radio uses port 80.

Changing the setup

Connection and password settings are in the server’s configuration file. Restart Retro Radio after changing them.

Audio formats

MP3 and AAC streams play directly. HLS and DASH streams are converted automatically. Protected streams cannot be played.

Station discovery uses Radio-Browser.
